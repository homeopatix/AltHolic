# Code de conduite

Nous voulons que ce projet reste un espace accueillant, respectueux et constructif pour toutes et tous.

## Notre engagement

Nous nous engageons à faire en sorte que la participation au projet soit une expérience exempte de harcèlement, de discrimination ou d'intimidation.

## Nos attentes

Les participants sont invités à :

- faire preuve de respect dans les échanges ;
- utiliser un langage clair, courtois et constructif ;
- tenir des discussions centrées sur le projet et ses objectifs ;
- accepter les retours de manière ouverte et professionnelle ;
- contribuer dans un esprit de collaboration et d'inclusion.

## Comportements inacceptables

Les comportements suivants ne sont pas tolérés :

- harcèlement, intimidation ou menaces ;
- commentaires offensants, insultants ou discriminatoires ;
- attaques personnelles ou commentaires déplacés sur l'apparence, les compétences, l'identité ou les opinions ;
- publication de renseignements privés sans consentement ;
- perturbation volontaire des discussions ou des contributions du projet.

## Portée

Ce code de conduite s'applique à tous les espaces du projet, notamment les issues, les pull requests, les discussions, les commentaires et toute interaction liée au dépôt.

## Réponse en cas de problème

Les mainteneurs peuvent, à leur discrétion, modifier, supprimer ou rejeter toute contribution qui ne respecte pas ce code de conduite. En cas de comportement inacceptable, les mainteneurs peuvent aussi limiter ou fermer l'accès d'un participant à un espace du projet.

## Signalement

Si vous êtes témoin ou victime d'un comportement inacceptable, veuillez contacter les mainteneurs du projet via GitHub. Les signalements seront examinés avec sérieux, confidentialité et souci de faire respecter ce cadre.

En participant à ce projet, vous acceptez de respecter ce code de conduite et de contribuer à un environnement sain, respectueux et collaboratif.
